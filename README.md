# Романтична гра для Ангеліночки 💓

Статичний сайт: HTML + CSS + чистий JavaScript, без залежностей і серверів.

```
romantic-game/
├── index.html   — розмітка екранів
├── style.css    — дизайн і анімації
├── script.js    — логіка (чіпати не потрібно)
├── config.js    — ВСІ тексти, дата, фото, музика
└── assets/
    ├── images/  — твої фото (jpg/png/webp)
    └── audio/   — music.mp3
```

## Локальний запуск
- Найпростіше: відкрий `index.html` у браузері.
- Або з сервером: у папці проєкту виконай `python3 -m http.server 8000` і відкрий `http://localhost:8000`.

## Персоналізація (усе в `config.js`)
- **Дата знайомства** — `metDate`, формат `"2024-02-14T18:30:00"`. Поки порожньо, показується заглушка.
- **Фото** — поклади файли в `assets/images/` і вкажи назви в `startPhotos` (рівень 1) та `memories` (рівень 2). Якщо файлу немає, показується заглушка 📷. Додавай картки в `memories`, копіюючи рядок. Стискай фото до ~1600 px по довшій стороні, щоб сайт швидко відкривався на iPhone.
- **Лист** — `letter.paragraphs` (кожен рядок — абзац).
- **Фінал** — `finalText`, `hiddenMessage`, за бажання `finalPhoto`. Фото також можна додати прямо на фінальному екрані (воно зберігається лише в її браузері).
- **Секрети** — `secrets` і `bonus`. Їх три: сердечко внизу рівня 2 (1 дотик), прикраса-сердечко на першому екрані (5 дотиків), назва рівня 4 (3 дотики).
- **Музика** — поклади власний файл як `assets/audio/music.mp3` (або зміни `music`). Використовуй лише музику, на яку маєш права. Звук вмикається тільки кнопкою 🔇/🔊; без файлу сайт працює без помилок.

## Збереження прогресу
Прогрес (рівні, спогади, секрети) і додане фото зберігаються в LocalStorage **конкретного браузера** на конкретному пристрої й не синхронізуються між пристроями. У приватному режимі Safari збереження може не працювати — гра все одно працюватиме. Кнопка ↺ («Почати спочатку») питає підтвердження.

## Розгортання на Cloudflare Pages
Інтерфейс Cloudflare змінюється, тому назви кнопок можуть відрізнятися. Актуальна інструкція: https://developers.cloudflare.com/pages/

**Спосіб A — через GitHub**
1. Створи репозиторій на GitHub і завантаж туди вміст папки `romantic-game` (`index.html` має лежати в корені репозиторію).
2. У панелі Cloudflare відкрий розділ Pages і створи проєкт із підключенням до Git; авторизуй GitHub і вибери репозиторій.
3. Налаштування збірки: фреймворк — немає (None), команда збірки — порожня, директорія виводу — корінь (за потреби звірся з документацією).
4. Запусти розгортання. Cloudflare видасть безкоштовну адресу виду `назва.pages.dev` — це і є посилання для надсилання.
5. Оновлення: змінюєш файли → commit/push у GitHub → сайт оновлюється автоматично.

**Спосіб B — пряме завантаження**
1. У Pages обери створення проєкту через пряме завантаження (Direct Upload) і завантаж папку проєкту або zip-архів.
2. Обмеження: немає автоматичних оновлень — для змін потрібно створювати нове розгортання; діють ліміти на кількість і розмір файлів (дивись документацію).
3. Якщо пізніше потрібен GitHub, створи новий проєкт зі Способу A.
